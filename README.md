# Times Tables Game

A fun, interactive game to help a third grader learn the multiplication table.

## Plan
- Plain HTML/CSS/JavaScript, no build step: open `index.html` in a browser.
- Dragon Egg Nursery: drag eggs into nests (rows x columns), type the total, hatch SVG baby dragons, and unlock times tables on a level map. Sounds are synthesized in the browser.
- Zombie Battle (optional): spend your hatched dragons to fight zombies. Each dragon has its own attack and damage, and tougher zombie kinds unlock with each map level.
- Tricks: short lessons for the times-5 trick (x10, then take away half) and the times-9 trick (x10, then take away one row). Finish the practice to earn a special dragon with a special attack in the Zombie Battle.

## Run
Open `index.html` in your browser.
